# SGSI - Sistema de Gestión y Seguimiento Clínico 🏥

**Proyecto Integrador Final (TP4) - Licenciatura en Informática**
**Autor:** Antonio David Toro Diaz Cornejo

## Descripción del Proyecto
El SGSI es un sistema desarrollado para el Centro de Salud "Bienestar Integral" con el objetivo de centralizar y unificar los historiales clínicos interdisciplinarios (Medicina General, Nutrición y Psicología) y gestionar la agenda de turnos. 

## Arquitectura y Tecnologías
* **Patrón de Arquitectura:** MVC (Modelo-Vista-Controlador).
* **Lenguaje:** Java (Interfaz gráfica con Swing).
* **Base de Datos:** Oracle Database.
* **Conectividad:** JDBC (Uso de `PreparedStatement` para seguridad y sentencias SQL optimizadas).
* **Estructuras de Datos:** Uso complementario de `ArrayList` (colecciones dinámicas) y `Arrays` (estructuras fijas).
* **Principios Aplicados:** Programación Orientada a Objetos (Abstracción, Herencia y Polimorfismo).

## Estructura del Repositorio
* `/src`: Código fuente estructurado en paquetes (`dt.modelo`, `dt.vista`, `dt.controlador`).
* `/sql`: Scripts DDL y DML para la creación e inserción de datos en Oracle (`BASE_DE_DATOS_SGSI.sql` y `consultas_sgsi.sql`).
* `TORO-DAVID-AP4.pdf`: Documentación técnica completa, diagramas (PUD, DER, Clases) y casos de prueba.
* `Presentacion_SGSI.mp4`: Demostración operativa del sistema.
